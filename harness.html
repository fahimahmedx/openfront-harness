THE WORK

One agent. One real game. A complete audit trail.

The model never controls the game directly. The harness observes the deterministic core, offers a bounded menu of legal actions, and records the result as replayable evidence.

  1. 01Observe

    Read fixed core state.

  2. 02Choose

    Select exactly two legal IDs.

  3. 03Execute

    Apply native game intents.

  4. 04Audit

    Inspect what GPT-5.6 saw, chose, executed, and cost.

AGENT CONTRACT

Bounded agency

Server-generated action menus, strict structured output, shared troop budgets, and deterministic fallbacks.

SIMULATION HARNESS
