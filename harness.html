THE ENGINEERING ARGUMENT

The benchmark is the boundary.

A model response is not evidence by itself. The harness makes the environment fixed, the choices bounded, and the result replayable through the real game engine.

“The hard part was building a trustworthy boundary between a probabilistic service and a deterministic game.”
01 / REAL SYSTEM

The actual game runs.

OpenFront’s pinned deterministic core handles the map, nations, combat, timing, victory logic, and state hashes.

02 / CONTROLLED AGENCY

The model cannot invent commands.

Every decision is limited to exactly two IDs from a menu of currently legal, server-generated actions.

03 / REPLAYABLE EVIDENCE

The trace follows the simulation.

Observations, actions, latency, tokens, cost, hashes, and native game intents remain synchronized during playback.
